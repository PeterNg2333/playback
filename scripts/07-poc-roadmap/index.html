未來實作的八道 gates

  1. Mode + privacyDemo/Real、dependency health、consent、retention、secret boundary
  2. Durable capture15 秒 WAV、partial→final、spool、restart recovery、3h capture
  3. SenseVoice throughputreal audio、latency、language accuracy、timeout/backoff、backlog slope
  4. Durable intake + PGidempotent key、STORED after persistence、ordered/versioned transcript

每道 gate 都保留可運行的上一層；例如 Gemini 壞了，audio + transcript 仍可用。不要同時做八層再一次過 debug。

Rolling note 為甚麼不能每次重送全堂課？

Context、latency 與成本會隨 lecture 長度持續上升。每版應讀「上一版 note + 尚未涵蓋的連續 transcript + relevant materials」，並存 throughSequence、model 與 revision。Transcript 中間有洞時，watermark 不可越過。

.NET Agent Framework 放在哪裡？

放在 AI Server 的 note/chat adapter。先用單一 Microsoft.Agents.AI agent，不用 Semantic Kernel，也不做 multi-agent。Gemini model ID、package version、quota 與 data terms 要在實作當日再核對及 pin。官方 Gemini table 對 C# hosted web search 標為不支援，因此 search 先做成 server-controlled adapter。

EVIDENCE

720 chunks 後仍成立，才叫三小時 POC

16 kHz mono PCM16 約 32 KB/s；三小時約 345.6 MB（329.6 MiB）。15 秒一段約 720 chunks。短 demo 看不到 queue leak、retry storm、file handle、thermal 或 long-context cost。

證據初始 pass gate必做 failure
Audio continuityduration vs wall-clock 差 ≤ 1%；0 無法解釋遺失UI close、server down、sleep
Idempotencyretry 後 0 duplicate logical chunksresponse lost、同段重送十次
ASR throughputsteady state backlog 不持續上升429、5xx、timeout、offline
Live latencyp95 chunk final → visible transcript ≤ 30sSSE disconnect/reconnect
Note latencyp95 schedule → stored revision ≤ 60smissing key、quota、transcript gap
Resource/costmemory 不線性增長；calls/tokens/cost 全記錄3h continuous load、disk low

這些是要驗證的初始門檻，不是現有成績或 SLA。測量後可以用 evidence 修訂。

FIRST CODE SLICE

第一刀只做一條完整路徑

3 fake WAV chunks
  → durable intake
  → explicit Demo ASR
  → PostgreSQL transcript
  → snapshot API
  → UI renders segments

Then resend chunk #2 → still one logical result

這一刀先不用真 mic、Gemini、search 或 mobile。它證明 contract、persistence、ordering、idempotency、reconnect，再逐個把 fake adapter 換成 Real。

CHECKPOINT

Gate 7 後才決定 MVP

Go

  • Audio durability/idempotency 過關。
  • ASR processing rate 追得上 lecture。
  • Note quality/cost 對學生有實際價值。
  • Consent 與 third-party data flow 可接受。

No-go / redesign

  • 任何短暫 outage 會永久丟 audio。
  • ASR backlog 在線上狀態仍線性增加。
  • Hallucination/citation 問題無法控制。
  • 三小時 battery/disk/cost 或 policy 不接受。
