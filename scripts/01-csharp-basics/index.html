概念地圖

types

資料有形狀；compiler 在 run 前找出不相容操作。

record

用 value equality 和 immutable copy 表示 audio/transcript message。

List<T>

一組有次序、而且全部同 type 的 chunks。

LINQ

過濾、排序、轉換，組成可讀的資料 pipeline。

nullable

「尚未有值」寫進 type intent，不用空字串假裝。

async / await

等待 ASR、database、LLM I/O 時不阻塞 thread。

error handling

預期的輸入問題用 TryParse；只 catch 真正懂得處理的 exception。

從 chunks 變成 note lines

List<LectureChunk>→ Where non-empty→ OrderBy sequence→ Select text→ ToList 
var noteLines = chunks
    .Where(chunk => !string.IsNullOrWhiteSpace(chunk.Text))
    .OrderBy(chunk => chunk.Sequence)
    .Select(chunk => $"{chunk.Sequence + 1}. {chunk.Text}")
    .ToList();

Record 是 data contract 的好起點

public sealed record LectureChunk(
    Guid SessionId,
    long Sequence,
    string Text,
    double DurationSeconds);

var cleaned = draft with { Text = draft.Text.Trim() };

with 產生修改過的 copy，不改原 object。相同 property values 的兩筆 record 會 value-equal。

Null 是狀態，不是空白字串

string? lecturerName = null;
string label = lecturerName?.Trim()
    ?? "（未提供講師名稱）";

? 告訴 compiler 這個 reference 可能沒有值；?. 安全存取；?? 提供 fallback。

Async 的心智模型

static async Task<string> NormalizeTranscriptAsync(string text)
{
    await Task.Delay(25);
    return text.ToUpperInvariant();
}

Task<string> 是將來會產生 string 的工作。await 不是「開新 thread」的同義詞；它讓 method 在工作完成後接續。

Error handling：不要靜靜吞掉錯誤

try
{
    _ = ParsePositiveInterval("-5");
}
catch (ArgumentOutOfRangeException exception)
{
    Console.WriteLine(exception.ParamName);
}

對正常而可預期的輸入分支，先用 int.TryParse；當資料違反 invariant，才 throw。Catch 具體 exception，讓未知錯誤繼續浮現，日後先分得清「AI server 可 retry」和「checksum 已損壞」。

為何沒有 .csproj？

.NET 10 可直接 build/run 單一 .cs。本課用 dotnet run --file basics.cs 明確選擇 file mode；正式 app 有多個 module、packages 和 tests 時，再轉 project。
