C# 入門 · .NET 10 · 完全新手

先寫一個檔案，再理解 .NET 專案

C# 是你寫的程式語言；.NET 是幫你執行它的工具和環境。先讓程式跑起來，不用先理解所有資料夾。

這頁會做甚麼

  1. 1. 準備工具
  2. 2. 第一個程式
  3. 3. 基本概念
  4. 4. 之後才學專案
  5. 5. 下一步

1. 你需要甚麼？

只需要安裝 .NET 10 SDK。SDK 是用來建立、執行和發布 C# 程式的工具組。VS Code 很方便，但不是必須；任何純文字編輯器也能編輯 .cs 檔案。

  1. 安裝 .NET 10 SDK。請選 SDK，不是 Runtime。
  2. 開啟 PowerShell：按 Windows 開始鍵，輸入 PowerShell，再按 Enter。
  3. 輸入以下指令，然後按 Enter：
dotnet --version

若看到 10.0.x，代表安裝成功。若剛安裝而看不到，先關閉 PowerShell，再重新開啟一次。

暫時不用安裝很多東西。

現在不需要 NuGet、Visual Studio、資料庫或專案模板。只要 SDK、文字編輯器和 PowerShell。

2. 寫第一個 C# 程式

.NET 10 支援單檔程式。所以第一個 Hello World 不需要 .csproj、obj 或模板。

建立練習資料夾

在 PowerShell 逐行輸入：

mkdir hello-csharp
cd hello-csharp

接著用 VS Code 或記事本建立一個名為 hello.cs 的檔案，把以下內容貼進去並儲存：

Console.WriteLine("Hello, C#!");

回到同一個 PowerShell 視窗，執行：

dotnet run hello.cs

你應該看見

Hello, C#!

目前只要記得這個流程：

改 hello.cs → 儲存 → dotnet run hello.cs

這一行是甚麼意思？

部分意思
Console.NET 提供的一個「文字視窗」工具。
WriteLine在文字視窗印出一行內容。
"Hello, C#!"要印出的文字。雙引號代表文字。
;這句 C# 指令的結尾。

3. 先學三個基本概念

以下每一段都是完整程式。練習時，把 hello.cs 的全部內容換成其中一段，再執行 dotnet run hello.cs。

把資料放進變數

string lecturerName = "Dr. Chan";
int slideCount = 42;

Console.WriteLine($"呢堂課由 {lecturerName} 教，用咗 {slideCount} 張 slide。");

lecturerName 和 slideCount 是變數名稱。string 表示文字；int 表示整數。$"..." 讓你能把變數放進文字的 { } 裏。呢個 app 之後會用差唔多嘅寫法記低講師、session、chunk 呢類資料。

根據情況做選擇

double chunkSeconds = 8;

if (chunkSeconds >= 10)
{
    Console.WriteLine("chunk 夠長，送去做語音辨識");
}
else
{
    Console.WriteLine("chunk 太短，繼續錄多陣");
}

if 是「如果」。大括號 { } 裏的指令，只有條件成立時才會執行。呢個 app 之後真係會用類似嘅判斷，決定一段錄音夠唔夠長先送去 ASR。

重複做事

for (int chunkNumber = 1; chunkNumber <= 3; chunkNumber++)
{
    Console.WriteLine($"Chunk {chunkNumber} 錄緊...");
}

這會印出「Chunk 1 錄緊...」到「Chunk 3 錄緊...」。現在不用背完整寫法；先知道 for 可以重複執行一段程式即可——一段三小時嘅錄音會產生成千上萬個 chunk，之後就係靠 for／foreach 逐個處理。

初學時的好習慣：一次只改一小段，執行後看結果。出錯很正常；錯誤訊息通常會告訴你檔案和行數。

4. 甚麼時候才需要 C# 專案？

當程式開始有多個檔案、想安裝函式庫、寫測試或發布應用程式時，才建立專案。這時可使用模板：

dotnet new console -n MyFirstApp
cd MyFirstApp
dotnet run

它會建立像這樣的資料夾：

MyFirstApp/
├── Program.cs          你主要會改的 C# 程式
├── MyFirstApp.csproj   專案設定
├── bin/                編譯後的程式，自動產生
└── obj/                建置與套件資料，自動產生

你只需要先碰前兩個檔案。bin 和 obj 是 .NET 的工作檔案，正常情況下不修改，也不需要閱讀。

.csproj 和 package.json 像嗎？

像。它們都記錄專案使用甚麼依賴和設定。差別是 .csproj 同時也記錄 .NET 要如何編譯程式。

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
  </PropertyGroup>
</Project>

目前你只要認得 TargetFramework：它表示「這個程式使用 .NET 10」。其餘設定可以等需要時再學。

之後想安裝函式庫

Node.js 常寫 npm install 套件名稱；.NET 常寫：

dotnet add package 套件名稱

這時 .NET 會在 .csproj 加入套件資料，並在 obj 產生需要的快取檔案。

5. 下一步怎樣學？

先把小程式寫順，比一次學完所有名詞重要。試做這三個練習：

  1. 把講師名同 slide 數量改成自己想像嘅堂課資料。
  2. 把 chunkSeconds 從 8 改成 12，睇下條件點樣變。
  3. 把迴圈嘅上限從 3 改成 10，想像成模擬十個 chunk 陸續錄完。

常見問題

看到甚麼？先做甚麼？
dotnet 不是命令安裝 .NET 10 SDK 後，關閉並重新開啟 PowerShell。
找不到 hello.cs先用 dir 確認檔案名稱；再確定 PowerShell 位於檔案所在的資料夾。
程式有紅字錯誤看錯誤訊息中的檔案名稱和行數；先檢查引號、分號和大括號是否成對。
