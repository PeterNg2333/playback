Adapter 內部的順序

  1. Validate
    不要相信 extension；檢查 magic、size 和固定 host。
  2. Compose
    MultipartFormDataContent 加入名為 file 的 StreamContent。
  3. Bound
    設定 timeout、cancellation 和 response size limit。
  4. Capture evidence
    先保存 status、content type 與 raw body。
  5. Normalize later
    觀察真實 schema 後才 parse 成自己的 AsrResult。

Timeout 不是「一定失敗」

Client timeout 只代表沒有及時收到答案；server 可能已處理 request。保留本機 WAV 與穩定 chunk identity，讓 retry 是可追蹤、可去重的操作。
事件應做的事
HTTP 2xx保存 raw response，再以經測試的 parser 正規化。
HTTP 4xx通常不要無限重試；檢查 format/contract。
HTTP 5xx / timeoutWAV 留在 spool，以 backoff retry。
Unexpected JSON視為 provider contract error；不要造一段假 transcript。
