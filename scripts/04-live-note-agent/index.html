MODULE 04 · SPIKE

筆記是一連串 revision。

不要每隔數分鐘「重做整堂課」。保存 transcript watermark，才知道模型已處理到哪裏，也能安全 retry。

1 · SAVEimmutable ASR chunk
2 · READwatermark 後的新文字
3 · EDITprevious note + material
4 · COMMITrevision + watermark

先跑 deterministic demo

& .\scripts\04-live-note-agent\study.ps1 -SelfTest

它故意再次送入 chunk 3，也嘗試在空 state 先送 chunk 2。正確結果是 duplicate 不改 state、gap 被拒絕；watermark 只可越過連續資料。

再明確選擇 Gemini

$env:GOOGLE_AI_STUDIO_API_KEY = '你的 key'
& .\scripts\04-live-note-agent\study.ps1 -Mode Gemini

# 較強、通常較昂貴的 consolidation experiment
& .\scripts\04-live-note-agent\study.ps1 -Mode Gemini -Model gemini-3.8-flash

預設 gemini-3.5-flash-lite。若 key 缺失或 request 失敗，script 會明確失敗；不會用 mock 冒充成功。

你正在讀的 C# boundary

var client = new Client(vertexAI: false, apiKey: apiKey)
    .AsIChatClient(model);

var agent = new ChatClientAgent(
    client,
    name: "RollingLectureNoteEditor",
    instructions: instructions);

AgentResponse draft = await agent.RunAsync(prompt);

await 讓 network I/O 不阻塞 thread；型別清楚標示 input/output。真正產品仍需驗證 draft，再寫 database。

Privacy checkpoint：lecture audio、同學發言、教材可能受私隱或版權規則約束。先取得同意，再把任何內容送到第三方 LLM。

Spike 通過才做的下一步

用相同 20–30 個 chunks 比較兩個 model：p50/p95 latency、token cost、source coverage、錯誤修正與 hallucination。數據支持後，才選 interval 和 model routing。
