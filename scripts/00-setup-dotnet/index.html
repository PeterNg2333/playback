先認識工具，再開始寫 C#。

這個 module 把「檢查」和「安裝」明確分開。你可以放心先跑檢查；沒有 -InstallMissing，系統不會被改動。

三步完成環境準備

01

Read-only check

.\scripts\00-setup-dotnet\study.ps1

報告 WinGet、SDK 10、VS Code、Docker CLI 與 engine 狀態。

02

Preview

.\scripts\00-setup-dotnet\study.ps1 `
  -InstallMissing -WhatIf

看到固定 package ID，但仍不安裝。

03

Explicit install

.\scripts\00-setup-dotnet\study.ps1 `
  -InstallMissing

只為缺少的項目呼叫 WinGet。完成後開一個新 terminal。

四件工具，各有一個角色

WinGet

可信的 package selector

用固定 ID 和 exact match，避免搜尋結果選錯軟件。

.NET SDK 10

Compiler + CLI + Runtime

SDK 是工作台；runtime 只是執行 app 的播放機。Package ID：Microsoft.DotNet.SDK.10

VS Code

Editor

再加 Microsoft C# Dev Kit，得到 IntelliSense、debug 和 testing UI。Package ID：Microsoft.VisualStudioCode

Docker Desktop

稍後裝 PostgreSQL

CLI 已安裝不等於 engine 已啟動；checker 會分開顯示。Package ID：Docker.DockerDesktop

PowerShell 說 script 被封鎖？

先確認你信任 repo 內容，再用只限單次 process 的命令：

powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\00-setup-dotnet\study.ps1

不要為了方便而永久關閉全機 execution policy。
