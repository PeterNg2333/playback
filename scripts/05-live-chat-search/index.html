先找證據，後寫答案。

即時 chat 的價值不是「回答得快」，而是能指出答案來自哪段 lecture、哪份教材或哪個外部來源。

安全的 default

& .\scripts\05-live-chat-search\study.ps1 -SelfTest

只讀本地 sample，證明三個結果成功 parse、off-domain citation 與超大 response 被拒，而且 query 不能改變固定 host。

明確開啟 online search

& .\scripts\05-live-chat-search\study.ps1 `
  -Mode Wikipedia `
  -Query 'voice activity detection'

這會輸出 evidence pack，不會假裝已經回答。下一步才是把 evidence IDs 交給 module 04 的 agent。

UI 最少要顯示

  • 答案中的 citation marker，例如 [L12] 或 [W2]；
  • lecture timestamp / material page / external URL；
  • 資料取得時間及「AI draft」狀態；
  • 搜尋失敗時的明確訊息，而非空白或虛構答案。

重要 boundary

網頁內容和 LLM output 都是不可信文字。固定 request/citation host、拒絕 redirect、encode query、限制 512 KB 和 12 秒；render 時只當文字，不能把內容直接放進 innerHTML、SQL 或 shell。
