# Phase 6 migration results

Date: 2026-10-08. Independent migration slice implemented; the prepared translation worker/use-case change awaits permission to include the pre-existing translation edit in a commit.

Plain transcript, audio-chunk, workspace, conversation, activity and term state now lives in Domain. BSON identity/ignore mappings live in Infrastructure and retain the legacy documents. Some public CLR namespaces remain `Playback.Api.*` for compatibility with existing callers; executable assembly checks establish the actual dependency boundaries. Domain and Application still reference no provider, storage or web frameworks.

Application owns transcription orchestration through preparation/provider/repository ports, term review/explanation, Ask and conversation context, activity lifecycle, workspace commands, recording controls, chunk imports and purpose-specific runtime/testing query ports. Infrastructure owns MongoDB, the existing Gemini/Agent Framework/Jev/ASR adapters, WAV/VAD/WASAPI, sync projections, native Cantonese display and hosted worker implementation. HTTP endpoints authorize/map transport data and invoke application services. Simple CRUD retains concrete feature repositories and shared domain validation.

Note saves advance one atomic `note_heads` document using expected version and a pending-history marker. Historical revisions append idempotently before the next head advance. Readers recover an interrupted history flush; original versions remain immutable. No multi-document transaction or database reset is required. Non-destructive recovery indexes are prepared for the next approved host start. Language/style snapshots still use current-settings validation and the shared per-process write lock; horizontal multi-host settings changes are not proven atomic across the settings/head collections.

ASR, note, term, combined-audio and index workers start through hosted lifecycle instead of constructor loops. Offline composition/start/cancellation/shutdown checks found and fixed repeated disposal of aliased singleton/hosted services. Quiet-stream lease heartbeats no longer request a full projection rebuild. Translation’s existing `targets.First().SessionId` selection is preserved in the prepared application workflow; its batching/parser/body has not been committed pending the outstanding approval. The independent migration commit keeps the legacy translation startup until that review unit is approved, so it builds without requiring the unstaged translation change.

New checks verify model/feature assembly ownership, domain independence, legacy BSON ignore fields/user identities, full service composition and lifecycle, real transcription orchestration/cancellation, atomic-head crash points and competing writers. Three-hour virtual acceptance also passed separately (2,700 sources, 45 fixture generations). No API host restart, live provider, database operation, container start or recording change was performed.
